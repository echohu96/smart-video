## 文档维护

### 文档更新原则

1. **文档即系统**：文档是系统的真实来源
2. **及时更新**：每次代码改动后立即更新文档
3. **保持同步**：确保文档与代码实现一致

详见根目录的 [.cursorrules](../../.cursorrules) 文件。

### 变更记录

所有文档变更记录在根目录的 [CHANGELOG.md](../../CHANGELOG.md) 中。
