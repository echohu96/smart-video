## 风险评估

1. **API 成本**：AI 总结会产生费用，需要控制使用量
2. **下载限制**：YouTube 可能有下载限制，需要处理
3. **字幕质量**：自动生成字幕可能不准确
4. **处理时间**：长视频处理时间较长
